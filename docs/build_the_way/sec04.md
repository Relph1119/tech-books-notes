# 第4篇 IT行业创新与职业道德

## 4.1 IT行业的创新

1. 团队惰性的破局
    - 时刻警惕”战略转折点“：主动在团队中制造危机感。
    - 鼓励”建设性对抗“：创造一种文化，让任何级别的员工都能坦诚地挑战现有战略和”神圣不可侵犯“的业务。
2. 创新的误区：
    - 创新不是”我能做什么“，而是”用户需要什么“；
    - 创新不是功能的堆砌，而是系统性的进步；
    - 创新不是目的，而是手段。
3. 颠覆性创新：回归第一性原则，要求创新者抛弃类比和现有经验，将一个产品或服务分解至其最基础的物理或成本要素，然后与当前的市场价格或性能作比较，如果发现二者有数量级的巨大差距，那么很可能出现颠覆性创新的机会。
4. NPS（净推荐值）= （粉丝所占的百分比） - （批评者所占的百分比），如果NPS在50以上，说明产品表现优秀。
5. 创新者的特质：
    - 戒：明确核心目标、核心资源和核心用户的边界。
    - 定：在”戒“所设定的边界内，锁定核心目标，以高一个数量级的标准服务核心用户。
    - 慧：将”偏执“转化为生存智慧的能力。
6. 小团队的成功路径：在正确的战场上做增量创新；用颠覆性思维重构商业模式。

## 4.2 人、绩效和职业道德

1. 领导力：
    - 技术领导力：为团队指明方向。
    - 思想领导力：洞见塑造团队认知。
    - 项目领导力：确保复杂目标达成的推动力。
2. 架构师或许不需要是编写某段具体代码最快的人，但能够识别人才、设定正确方向、传授设计理念，并在团队受挫时激发其潜能。
3. 领导者的核心任务是快速建立清晰的5P框架：
    - 目的：我们为何存在？
    - 原则：什么是我们的底线？
    - 优先级：当资源紧张时如何取舍？
    - 计划：制订切实可行的路线图。
    - 人员：明确每个关键领域的负责人、问责人和参与者。
4. 真正的英雄不是那些深夜救火的人，而是那些通过卓越设计让火灾根本不会发生的人。
5. NVIDIA模式：
    - 用持续反馈取代绩效报告
    - 消除内部竞争，聚焦共同目标
    - 视员工为长期资产，而非可替换资源
